# UI/UX Enhancement Prompt — Visual Only (No Logic Changes)

Enhance the visual interface of this application. **Do not modify any FastAPI backend logic** — only the frontend/UI layer.

---

## General Design Direction
- Keep the existing color palette but refine it — use harmonious, muted nuances that feel smooth and cohesive
- Add SVG decorative elements for a modern, polished aesthetic
- Target users are non-technical: the experience must feel intuitive and frictionless

---

## User Flow
- Remove any explicit "Step 1 / Step 2 / Step 3" feeling
- Guide the user naturally from one action to the next via **progressive disclosure** — each step seamlessly reveals itself after the previous one is completed

---

## Forms
- Redesign all forms for clarity and ease of use
- Clear labels, proper spacing, visual feedback on interaction (hover, focus states)
- Inline validation where relevant

---

## Data Visualization
- Replace raw dataframe displays with clean, styled tables (alternating rows, proper headers, readable typography)
- For charts: adjust color schemes to be harmonious with the background — smooth palette nuances, no harsh contrasts

---

## Sidebar
- Reconsider the sidebar layout — reposition or redesign it to feel less like a navigation panel and more like a **contextual companion** to the main content

---

## Dynamic & Smooth Feel
- Add subtle transitions and animations where appropriate (fade-ins, slide-ins, loading states)
- The interface should feel alive and responsive, not static
